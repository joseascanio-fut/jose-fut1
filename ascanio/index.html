Aprende C# desde cero

1. ¿Qué es C#?

C# es un lenguaje de programación creado por Microsoft. Se usa para hacer programas, aplicaciones, videojuegos y sistemas web.

2. Tu primer programa

Este código muestra un mensaje en pantalla:

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hola, mundo");
    }
}

Console.WriteLine() sirve para mostrar texto en la consola.

3. Variables

Una variable guarda información para usarla después.

string nombre = "Ana";
int edad = 20;
double altura = 1.70;
bool esEstudiante = true;

Console.WriteLine(nombre);
Console.WriteLine(edad);

Tipos más comunes:

  • int: números enteros, por ejemplo 20.
  • double: números decimales, por ejemplo 1.70.
  • string: texto, por ejemplo "Ana".
  • bool: verdadero o falso.

4. Condicionales

Con if el programa toma decisiones.

int edad = 18;

if (edad >= 18)
{
    Console.WriteLine("Eres mayor de edad");
}
else
{
    Console.WriteLine("Eres menor de edad");
}

5. Bucles

Los bucles repiten código varias veces.

for (int i = 1; i <= 5; i++)
{
    Console.WriteLine("Número: " + i);
}

Este código muestra los números del 1 al 5.

6. Funciones

Una función sirve para reutilizar código.

static int Sumar(int a, int b)
{
    return a + b;
}

static void Main()
{
    int resultado = Sumar(5, 3);
    Console.WriteLine(resultado);
}

El resultado será 8.
